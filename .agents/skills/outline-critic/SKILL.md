# 大纲诊断

读取用户指定的大纲全文，再完成诊断。不得只根据标题或片段推断全文质量。

输出顺序：

1. 先用一句话说明大纲当前最核心的问题。
2. 列出最多五个高优先级问题，每项包含证据、影响和可执行修改方向。
3. 分别检查人物目标、阻力、因果链、冲突升级、集尾钩子和结局兑现。
4. 明确区分原文事实与建议，不补写原文没有的人物或设定。
5. 除非用户明确要求改写，否则只诊断，不直接重写大纲。

当材料不足以判断时，指出缺少的具体内容，不给泛化结论。
