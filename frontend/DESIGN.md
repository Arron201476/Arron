# 内容生产 Agent 前端基线

## 产品气质

这是高频内容生产工作台，不是营销页。界面以可扫描、可比较、可持续操作为优先，保留左侧流程目录、中间产物工作区、右侧 Agent 协作区的稳定心智。

## 颜色角色

- 蓝色：唯一主操作与键盘焦点。
- 青绿色：生成中、已完成、引用上下文等生产状态。
- 琥珀色：等待确认、暂停和需要用户决策。
- 红色：失败、取消与不可逆操作。
- 中性色：页面结构、次要按钮、文本和分隔。

同一操作组内不允许两个视觉权重相同的主按钮。

## 组件规则

- 普通按钮高 34-36px，圆角 6px；图标按钮使用固定方形点击区并居中 Lucide 图标。
- 下拉触发器使用 Lucide `ChevronDown`，图标盒固定 32px；展开时旋转，必须提供 `aria-haspopup` 和 `aria-expanded`。
- 菜单项最小高 44px，标题和说明分层；悬停、选中、禁用和键盘焦点均需可辨认。
- Agent 确认卡只保留一个主操作，编辑、取消等动作降为次级按钮或文本动作。
- 工作区表面分层：目录浅色、编辑画布冷灰、内容纸张白色、Agent 面板白色；不使用整页同色铺底。
- 信息密度由间距和字号建立，不通过大量卡片嵌套制造层级。

## 验收

- 1280px 以上三栏无重叠；窄桌面允许中间内容内部重排，不丢失左右主导航。
- 所有可点击图标均有可访问名称，文本不截断到无法识别，菜单对齐触发器右缘。
- 业务能力、产物结构和现有流程不因视觉改造改变。
