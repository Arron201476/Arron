# 06_转场_闪回_连续性_格式

## 名称
06_转场_闪回_连续性_格式

## 用途描述
用于需要输出中文剧本的步骤，提供共享的转场、闪回、连续性和中文剧本格式准则。

## 使用模式边界

- 正向剧本生成：执行本 Rule 的全部规则。
- 视频反向剧本提取：只执行“中文剧本格式规范”及其排版、标注、镜头语言限制；剧情、场次、转场、闪回、对白和人物状态必须忠实于源视频，不得为了满足创作性要求而删改、补写或重排视频内容。
- 当格式规则与忠实还原冲突时，视频反向提取以源视频事实和逐字字幕证据优先，格式只负责呈现，不改变内容。

## 准则
### 短剧时间与转场引擎


### 参考范围

参考情况：

- 有闪回
- 有倒序开头
- 有跨时间段叙事
- 场景地点频繁切换
- 角色从 A 地突然到 B 地
- 需要补充关键因果
- 上一集尾钩与下一集开头需要承接

### 使用原则

1. 转场必须保证观众知道时间、地点和人物状态。
2. 闪回必须服务当前冲突，不做纯回忆。
3. 倒序只能使用本集或已知事件，不能新增真相。
4. 时间跳跃必须交代触发点和后果。
5. 连续性优先于节奏压缩。

### 转场类型

#### 1. 动作转场

用人物行动连接场景，例如离开、赶往、打开门、接电话后切场。

#### 2. 物件转场

用证据、信物、照片、药、合同、手机信息等连接。

#### 3. 声音转场

用电话、广播、敲门、警报、音乐或对白尾音连接。

#### 4. 情绪转场

用人物情绪从上一场延续到下一场，但必须有具体动作承接。

#### 5. 时间标识转场

用于必要跳时，例如“翌日清晨”“三小时后”。不能用时间标识跳过关键因果。

### 闪回使用规则

闪回只能用于：

- 揭示人物动机
- 补充关键因果
- 展示过去创伤
- 解释当前误会
- 释放部分真相

避免：

- 连续大段闪回
- 闪回中再套闪回
- 用闪回替代当前行动
- 用闪回解释观众已理解的信息

### 引用边界

使用时应影响以下内容：

- 场景之间的连接方式
- 闪回是否必要
- 闪回如何自然引出
- 时间跳跃是否清楚
- 跨场和跨集连续性

### 禁止越权

1. 不用转场跳过关键因果。
2. 不让角色无解释瞬移。
3. 不让闪回新增原文没有的核心事实。
4. 不把倒序开头写成本集以外的未知大事件。
5. 不为了节奏牺牲观众理解。

### 中文剧本格式规范
### 参考范围

本规范约束：

- 集标题
- 场景标题
- 人物列表
- 人物首次出场
- 舞台指示 / 动作描写
- 对白
- OS / VO / 画外声
- 闪回
- 场景转换
- 音效
- 屏幕文字 / 插入画面

### 制作铁律

#### 1. 禁用镜头清单

1. 空镜 / 建立镜头：纯风景、纯环境、无人物动作。
2. 慢镜头：任何形式的慢动作回放。
3. 发呆镜头：角色呆站、沉思、望向远方、白日梦。
4. 背影镜头：拍摄人物后脑勺或背面作为主要表达。
5. 让观众猜角色意图的模糊镜头。
6. 淡入、淡出、叠化等软转场。
7. 纯回忆、纯闪回集。
8. 纯铺垫、纯独白、纯日常镜头。

说明：禁止的是无功能废镜头。必要的动作桥、反应桥、空间确认、信息落点、结果反馈可以保留。

#### 2. 场景连续性

场景之间必须保证行动、空间、人物状态连续。不得让人物、物品、地点、伤势、关系状态突然变化。

#### 3. 对白格式边界

本规则模块 只规定对白在剧本中的呈现格式和连续性位置；对白功能、声口、长短、潜台词和独白控制归 `05_对白规则.md`。

1. 对白必须标明说话角色。
2. 同一场景中对白要和人物动作、位置、转场状态保持连续。
3. 画外音、OS 和普通对白必须区分清楚。
4. 不在本规则模块 中重复维护对白写法准则。


### 格式规范

#### 1. 语言要求

全部使用简体中文。所有场景描写、对白、舞台指示、标注全部使用中文。

例外：`VO` / `OS` 作为结构缩写允许保留。

#### 2. 集标题

每集以集标题独立成行。

格式：

第{EP}集

规则：

- 使用阿拉伯数字，不使用中文数字。
- 第一个非空行必须是当前请求集数的标题。
- 集标题与第一场之间保留一个空行。

#### 3. 场景标题

格式：

场{EP}-{SCENE} 地点 时间 内/外

示例：

场3-1 医院走廊 夜 内
场3-2 小区门口 黄昏 外

规则：

- `场` 后的前半段必须等于当前集号。
- 当前是第 3 集时，只能写 `场3-1`、`场3-2`，不能写 `场1-1`。
- 地点名称要稳定，首次出现后后续复用。
- 时间优先使用：日、夜、清晨、上午、中午、下午、傍晚、深夜、黎明、黄昏。
- 室内外用 `内`、`外` 或 `内/外` 标明。

#### 4. 人物列表

场景标题后紧跟人物列表。

格式：

人物：角色A、角色B、保镖*2

规则：

- 群众演员用 `*N` 表示。
- 仅以声音出现的角色加 `VO`，例如 `助理（VO）`。
- 人物列表中只写本场实际出现或发声的人物。

#### 5. 人物首次出场

角色在全剧首次出场时，在动作行内简要标注：

△林夏（24岁，白衬衫）推开病房门。

规则：

- 标注控制在 16 字以内。
- 年龄必须保持一致。
- 后续再次出现直接使用角色名，不重复外貌描述。
- 只有外貌发生剧情相关变化时，才重新补充描述。

#### 6. 舞台指示 / 动作描写

使用 `△` 标记动作行。

规则：

1. 使用现在时。
2. 描写具体、可视化、适合拍摄。
3. 每个 `△` 行优先只承载一个核心动作变化。
4. 不写空泛抒情句。
5. 不只写结果，要尽量写清结果如何发生。
6. 不堆叠过多新设定、新能力、情绪翻转或他人反应。
7. 每集最多 2 行纯氛围/环境描写。

#### 7. 镜头标注

`△` 行不写镜头类型，不写运镜指令。

禁止：

- 特写
- 中景
- 远景
- 俯拍
- 推镜头
- 慢动作
- 色调
- 构图

#### 8. 对白

格式：

角色名：（语气）台词。
角色名：台词。

规则：

- 语气括号可选，只写说话方式，例如冷声、咬牙、低声、急切、讥笑。
- “可选”指按表演需要选择，不是随机省略：态度、强度或真实意图发生关键变化且动作不足以表达时应标注；其余对白不标，避免每句都带括号。
- 对白内容遵守 `05_对白规则.md`，本处只规定呈现格式。

#### 9. 画外音与画外声

格式：

角色名OS：内心独白。
角色名VO：画外音。

规则：

- OS 用于内心判断、隐藏动机、关键信息反应。
- VO 用于画外声音、电话声、广播声等。
- 不要用 OS 复述画面。

#### 10. 闪回

闪回必须穿插在当前剧情中，不能整集纯闪回。

格式：

闪回：三年前，医院走廊。

规则：

- 闪回必须有触发物或触发台词。
- 闪回结束后必须回到当前场景。

#### 11. 场景转换

只允许硬切式转换。

可写：

△林夏推门冲出病房。

场3-2 医院楼梯间 夜 内
人物：林夏
△林夏扶着墙停下。

禁止写：

- 淡入
- 淡出
- 叠化
- 镜头切换到

#### 12. 音效

音效只在推动剧情或制造压力时使用。

格式：

音效：手机震动。

#### 13. 屏幕文字 / 插入画面

格式：

屏幕文字：银行卡余额不足。
插入画面：监控截图显示林夏进入医院。

规则：

- 必须是观众需要看见的信息。
- 不要滥用。

#### 14. 通用排版

1. 场与场之间保留一个空行。
2. 同一场内不要出现无意义空行。
3. 不使用 Markdown 标题。
4. 不使用代码围栏。

### 干净转场与视听表达

1. 转场必须短、清楚、有功能；不要为了表现“电影感”写长铺垫、长空镜或无信息镜头。
2. 场景切换优先使用动作、物件、声音、手机信息、门铃、脚步、警报、证据露出等可拍触发点。
3. 回忆和前情信息优先考虑闪回、物件触发、声音触发、画面反差或角色即时反应，不只依赖角色口头解释。
4. 音效、光影、镜头提示只能在推动压力、悬念、记忆触发或信息揭示时使用；不能作为装饰性描写堆叠。
5. 需要承接上一集尾钩时，转场要直接进入尾钩后果，不重播、不绕远、不用大段解释稀释紧张感。
6. 视听表达必须服务剧情可拍性和观众理解，不牺牲因果清晰度。
