# 01_素材理解与故事圣经

## 名称
01_素材理解与故事圣经

## 用途描述
仅用于小说链路 Step1 全文理解，提供原文事实整理、故事圣经、短剧化资产识别和改编风险识别的参考准则；后续步骤通过故事圣经间接消费其结果，不再直接引用本规则模块。

## 准则
### 全文理解准则
### 要求规范

1. 必须忠实基于已读原文，不得编造后续未出现剧情。
2. 未完结或原文未覆盖的阶段，只能标记为素材未覆盖，不得补写后续剧情。
3. 可以识别原文中的剧情功能、人物关系和明显风险点，但不要把高风险原文表达写成后续必须原样呈现的创作要求。
4. 角色信息要服务短剧生产，重点写清身份、关系、目标、冲突、外貌、性格和可视化特征。
5. 外貌描写必须具体，包含发型发色、眼睛、肤色、面部、身形，以及至少 2 套可拍摄服装。
6. 人物梳理优先覆盖主角、主要对手、核心关系人物和高频配角。

### 短剧化改编诊断


### 参考范围

素材已经进入改编流程时，可参考短剧化强化方向、改编风险和后续规划重点。

参考素材：

- 小说原文
- 故事梗概
- 灵感点子
- 人物设定

### 使用原则

2. 优先诊断短剧观看价值，而不是文学价值。
3. 优先识别核心情绪、强冲突、爽点、钩子和人物关系。
4. 所有强化建议必须基于已提供材料，不得编造未出现设定。
5. 诊断结果要能转化为 分集规划 的开头、冲突、爽点、尾钩和 剧本生成 的场面化写法。

### 诊断维度

#### 1. 核心梗是否需要提纯

合格的短剧核心梗应能在一句话内讲清：

- 主角是谁
- 主角遇到什么压迫或诱惑
- 最大反差是什么
- 观众为什么想继续看

如果核心梗不清楚，故事圣经应标记后续需要提纯：

- 只有世界观，没有人物困境
- 只有感情氛围，没有冲突事件
- 只有设定新奇，没有追更机制
- 需要大量解释才能理解卖点

#### 2. 情绪驱动力要不要前置

重点识别以下情绪：

- 被轻视后的证明
- 被背叛后的反击
- 爱而不得
- 被误解后的澄清
- 身份落差
- 阶层压迫
- 家庭、爱情、事业中的强选择

短剧不怕情绪直接，怕情绪模糊。

如果情绪驱动埋得太晚，分集规划 应优先在前几集规划中前置可见的压迫、误会、诱惑、选择或反击动机。

#### 3. 爽点和反转是否需要加密

检查素材是否包含：

- 打脸
- 反击
- 身份揭露
- 证据出现
- 危机逆转
- 误会升级
- 权力关系变化
- 情感关系转向

如果爽点稀疏，应标记为后续规划风险：分集规划 要在不新增关键事实的前提下，把已有局势变化改造成更清楚的爽点链。

#### 4. 哪些内容适合场面化

适合短剧的素材通常有明确场景、行动、对白和外部压力。

需要改编处理的内容包括：

- 大量心理描写
- 大量设定说明
- 大量抽象情绪
- 场景昂贵或特效依赖强
- 人物过多、支线过散

故事圣经应标记哪些心理、说明和抽象情绪可以转化为可拍的动作、对话、物件、场景压力或人物选择。

### 禁止越权

2. 不生成剧本正文。
3. 不改写原文事实。
4. 不为了提高适配度新增关键设定。
5. 不覆盖已经确定的素材边界。

### 网文转短剧改编


### 参考范围

小说原文、网文章节、小说大纲或长篇故事素材。

### 使用原则

1. 网文改短剧不是搬运原文，而是用短剧观看逻辑重组素材。
2. 必须保留原文核心情绪、核心关系、关键因果和高价值爽点。
3. 可以删减、合并、压缩低价值支线，但不得越过已经确定的素材边界。
4. 心理描写应转化为动作、对白、选择、证据、误会或对抗。
5. 不因短剧化而编造原文没有的关键事实。

### 改编参考

#### 1. 保留项

优先保留：

- 核心梗
- 主角最强处境
- 主要人物关系
- 高点击事件
- 情绪爆点
- 身份或资源反转
- 原文关键台词
- 推动因果的桥段

#### 2. 合并项

可合并：

- 功能重复的配角
- 同质化反派
- 重复误会
- 重复打脸
- 多条弱支线

#### 3. 删除项

可删除：

- 纯环境描写
- 无信息过渡
- 反复解释设定
- 不影响主线的副本
- 低冲突日常

#### 4. 前置项

可前置：

- 原文已有的高潮事件
- 原文已有的身份线索
- 原文已有的危机
- 原文已有的关系破裂或情绪爆发

不得前置不存在的关键设定。

### 人物改编

检查原作人物是否适合短剧观众：

- 长期被动的主角需要增加阶段性行动。
- 过度恋爱脑角色需要设计觉醒节点。
- 反派需要明确利益和行动目标。
- 配角要有明确剧情功能。

人物重塑必须作为全局策略在前期确定，不应在剧本正文阶段临时改变人物底层设定。

### 禁止越权

1. 不把改编方案直接当成剧本正文。
2. 不新增关键设定。
3. 不破坏原文已建立的因果链。
4. 不在分集规划中破坏既定素材边界。
5. 不为了爽点删除关键情感铺垫或人物转变。
