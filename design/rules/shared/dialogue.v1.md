# 05_对白规则

## 名称
05_对白规则

## 用途描述
用于 Step4 剧本生成，提供对白功能、人物声口、冲突台词和潜台词准则。

## 准则
### 短剧对白引擎

### 参考范围

参考问题：

- 对白太长
- 对白解释过多
- 人物说话同质化
- 对白不能推动剧情
- 爽点靠喊口号
- 情绪只靠 OS
- 人物行动和对白不一致

### 使用原则

1. 每句对白尽量只表达一个意图。
2. 少解释，多逼迫。
3. 少说结论，多制造对方反应。
4. 重要信息尽量通过质问、证据、隐瞒、打断或选择表达。
5. 台词要符合人物身份、关系位置和当下处境。
6. 对白必须服务剧情、关系、信息、爽点或悬念。

### 对白功能

#### 1. 逼问

用于迫使对方暴露信息或态度。

示例功能：追问证据、追问关系、追问动机。

#### 2. 威胁

用于加压，让人物必须行动。

威胁必须绑定具体代价，不要只说狠话。

#### 3. 隐瞒

用于制造悬念或误会。

隐瞒不能破坏观众理解，至少要让观众知道有信息差。

#### 4. 反击

用于完成局势翻转。

反击台词要配合证据、动作或资源变化，不能只靠气势。

#### 5. 情感推进

用于关系确认、破裂、试探、道歉或拒绝。

情感台词要具体，避免空泛表白和大段抒情。

### 人物声口

设计人物声口时，至少区分：

- 说话长短
- 情绪外露程度
- 攻击方式
- 是否爱解释
- 是否直接表达需求
- 是否回避真实情绪

不要让所有角色都用同一种短剧爽文口吻。

### 引用边界

使用时应直接影响剧本正文：

- 人物对白更短、更准、更有信息量
- 不同角色的声口更容易区分
- 对白推动冲突、关系、信息或情绪
- 减少解释性对白和无效寒暄

### 禁止越权

1. 不为了金句牺牲人物动机。
2. 不用台词解释本该被画面展示的事件。
3. 不在对白里新增原文没有的证据或秘密。
4. 不让人物突然知道自己无从得知的信息。
5. 不把全部 OS 改成对白；必要的内心信息可以保留短 OS。

---

### 长台词与独白控制

1. 单角色连续表达过长时，优先拆成“对方打断、反问、行动反应、信息递进、沉默压力”组成的互动冲突。
2. 独白只保留无法通过动作、表情、物件或对手反应表达的必要心理信息，且必须短。
3. 解释型台词要转成场面信息：证据、物件、手机内容、第三方反应、动作选择或当场冲突。
4. 台词不能为了解释设定而暂停剧情；每段对白都要推动关系、信息、冲突、爽点或悬念至少一项。
5. 角色连续发言如果超过两三句，必须检查是否可以插入对手反应、动作变化或场景压力。
6. 拆分长台词不能新增关键事实；只能改变表达方式和冲突节奏。
