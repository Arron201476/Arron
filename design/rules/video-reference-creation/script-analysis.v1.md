# 漫剧参考剧本分析规则

## 适用范围

仅由 `video_reference_creation.analyze_reference_scripts` 使用。输入是已经确认的整剧 `reference_scripts`，输出是 `script_analysis`。

本 Rule 不参与 Capability 路由，不负责视频提取，不生成改编剧本。

## 基本原则

1. 先判断材料完整度。缺失处写“材料未明确”，不得补造不存在的集数、台词、事件或人物弧光。
2. 事实层和建议层必须分开。建议新增内容必须明确标记为建议。
3. 关键判断尽量绑定 `episode_no`、事件、动作、Scene/Line 或短台词证据。
4. 不只复述剧情，要形成可用于后续改编决策的业务判断。
5. 同一事实只在最合适的模块详细展开，其他模块引用，避免重复。

## 分析范围

必须覆盖：

1. 基础信息、材料完整度、Logline、剧情简介和世界观；
2. 综合潜力、最大优势、最大短板、形态适配度和原因；
3. 开头类型、节奏、信息密度、主角处境和开头风险；
4. 核心梗、钩子机制、铺垫、兑现和商业价值；
5. 爽点、虐点、首次强兑现和情绪释放路径；
6. 剧情驱动、情绪曲线、悬念和代入点；
7. 人物设定、人物关系、目标、阻碍、弧光、语言特征和记忆点；
8. 逐集事件、关键冲突、结尾卡点和转化点；
9. 差异化来源、核心爆点和同质化风险；
10. 可迁移的结构、节奏、关系和情绪方法；
11. 风险、影响和修改方向；
12. P0/P1/P2 优化动作；
13. 可用于投流的素材方向；
14. 最值得保留、最需要加强和是否建议推进的结论。

## 证据要求

- 事实判断至少绑定一个来源引用；
- 台词只能引用参考剧本中存在的短台词；
- 没有明确证据时写“材料未明确”；
- 推断必须声明推断边界；
- 不把爆款概率、评分或建议伪装成客观事实。

## 可复制与禁止照搬

可以提取：

- 开场钩子模式；
- 冲突升级规则；
- 人物关系动力；
- 情绪释放节奏；
- 单集卡点方法；
- 视觉化场景类型；
- 对白风格原则。

不得建议直接复制：

- 具体人物名和独特身份组合；
- 连续事件链；
- 标志性台词；
- 专有世界观设定；
- 高辨识度桥段顺序；
- 其他足以形成实质性复刻的内容。

## 优先级

- `P0`：影响理解、留存、付费、核心爽感或人设口碑；
- `P1`：显著提升传播、追更或情绪强度；
- `P2`：提升质感、效率或台词传播性。

## 输出边界

只输出符合 `scriptAnalysis` JSON Schema 的数据，不输出分析过程，不直接生成 `adaptation_brief`。

- 所有面向用户的分析、判断与建议使用简体中文；专有名词可保留原文。
- 必填模块必须包含实质分析。不得输出空字符串、空数组或“暂无”占位；材料确实不足时写明“材料未明确”及受影响范围。
