# 参考改编禁止照搬规则

## 适用范围

仅用于 `video_reference_creation` 的改编方案与 Brief 步骤。

## 规则

1. 只能迁移抽象结构、节奏、冲突机制、关系动力和情绪方法。
2. 默认替换具体人物身份、专有名词、世界观表达、连续事件链和标志性桥段。
3. 不复用参考剧的标志性台词，不做近义词替换式改写。
4. 每套方案必须说明保留的是哪类方法、替换的是哪些具体内容。
5. 用户要求直接照搬时，必须拒绝该部分并引导为结构级参考。
6. 第一版只提供来源标记、禁止照搬约束和用户确认，不声称完成自动版权检测或法律合规审查。
7. `adaptation_brief.forbidden_copying` 不能为空。
