# 旧版 Agent 交互复用审计

## 本轮已复用

- 剧本产物按类型进入独立编辑器，不再使用过程产物的通用字段表单。
- 保留分集目录，并在当前集存在未保存修改时阻止切集。
- 剧本编辑器内常驻撤销、重做、保存状态、取消和保存新版本。
- 支持 `Ctrl+S` 保存。
- 普通过程产物的保存与取消移动到工作区固定工具栏，滚动正文时仍可操作。
- 保存仍使用当前项目的 Artifact 新版本与 `handoff_refresh_required` 协议，没有迁回旧版直写接口。
- 小说、非小说和视频链路共用同一套 `script_unit` / `video_script_unit` 编辑体验。

## 当前已具备，无需从旧版迁移

- 作品级上下文、一个 Run 一条主链、多个 Skill 的历史运行目录。
- Artifact 版本历史、最终稿候选、审批、暂停、恢复、重试与事件流。
- Agent 对话、能力引用、配置卡和视频批次状态。
- 未保存状态下切换左侧产物的全局确认保护。

## 暂不迁移

- 旧版“选中剧本文字后让 Agent 局部修改”：需要先定义 General Agent 的选区 Action Contract、版本基线和下游失效策略，不能直接复用旧垂类 Agent 命令。
- 旧版评论节点、建议节点和富文本标记：当前 P0 剧本交付是结构化纯文本，先保证逐字编辑和版本一致性。
- 旧版 API、小说/非小说模式开关、垂类状态机与路由判断：这些属于旧 Agent 业务逻辑，不进入当前 Skill。
- 旧版直接更新 Artifact 的冲突处理：当前继续以不可变版本和 Runtime handoff 刷新为权威。

## 验证证据

- `editor-comparison.png`：旧版、当前改前、当前整改后的同视口对照。
- 小说剧本：专用编辑器存在，修改后切集被拦截，保存按钮滚动后仍在视口，取消退出成功。
- 视频还原剧本：同一专用编辑器路由成功。
- 普通过程产物：滚动后保存按钮位于工作区顶部。
- 前端测试 23 项通过，生产构建通过。
