## 6. 证据边界

Figma 证据可以证明布局、组件状态、文本适配、原型跳转和静态可读性；不能据此宣称前端已满足键盘顺序、`aria-label`、真实 `focus-visible`、屏幕阅读器播报或 WCAG 完整合规。这些必须在前端实现阶段继续验证。

同样，节点扫描、无越界和状态齐全不能证明组件具有专业视觉质量。旧批次因这一判断错误整体失效。
