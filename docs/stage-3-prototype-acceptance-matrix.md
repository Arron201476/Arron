## 1. 原型完成口径

阶段 3 的低保真不是静态页面集合，而是使用确定性模拟数据运行的 P0 流程模拟器。

每个可见控件必须满足以下任一条件：

1. 可以执行，并产生明确、可验证的下一状态；
2. 明确禁用，并说明当前不可执行的原因。

原型不连接真实后端和模型，不验证内容生成质量，也不决定阶段 4 的最终视觉。

## 2. 核心路径

| 路径 | 起始状态 | 必须可执行的动作 | 结束状态 | 异常与恢复 |
|---|---|---|---|---|
| P3-F01 作品管理 | 作品入口 | 新建、打开、搜索、筛选、行内重命名、删除确认 | 作品列表或空作品工作台 | 取消删除、Esc 关闭、点击菜单外关闭 |
| P3-F02 通用入口与路由 | 空作品 | 添加模拟材料、引用 Skill、自然语言发送 | 明确 Skill 或澄清问题 | 上传不自动启动；意图不明时追问 |
| P3-F03 小说主链 | 故事圣经待确认 | 编辑、AI 修改、重生成、影响确认、逐步确认 | Candidate | 暂停、恢复、取消、失败重试 |
| P3-F04 非小说主链 | 材料完整度待确认 | 选择扩写策略、逐步确认共享产物、统一确认剧本 | Candidate | 材料不足时不能静默继续 |
| P3-F05 视频主链 | 视频批次解析中 | 添加批次、失败单集重试、排序、明确上传完成、缺集确认、参考剧本、分析、方案、Brief、共享后续链 | Candidate | 缺集、失败、暂停、恢复、取消 |
| P3-F06 编辑与版本 | 任一用户可见产物 | 手动编辑、保存、AI 修改、重新生成、查看版本 | 新版本待确认 | 修改已确认上游前展示下游影响 |
| P3-F07 Candidate 与 Final | 多个 Candidate | 查看、选择、改选、导出、发起修订 | 唯一当前最终稿 | 未选择 Final 时阻止导出 |
| P3-F08 切换与恢复 | 任一进行中作品 | 返回入口、打开另一作品、重新进入原作品 | 恢复离开前状态 | 不同作品状态隔离 |

## 3. 状态覆盖

| 状态 | 原型证据 |
|---|---|
| 空作品 | 可添加材料或通过 Agent 开始 |
| 意图不明确 | Agent 追问材料用途，不启动 Run |
| 等待配置 | 显示集数、单集时长等必要配置 |
| 运行中 | 历史原型为 Composer 锁定；后续实现按新定位与修改合同保持输入，并区分只读消息、排队修改和新 Skill 冲突 |
| 等待确认 | 完整产物、编辑、重生成和确认同时可见 |
| 已暂停 | 显示恢复和取消，不显示继续输入造成并发写入 |
| 失败 | 显示失败位置、原因和重试 |
| 上游已修改 | 展示受影响下游及保留/重生成选择 |
| 已完成 | Candidate、Final 和导出入口稳定 |
| 服务断开 | 写操作禁用并说明恢复状态 |

## 4. 交互语义门禁

- 行级 `···` 使用锚定 Menu/Popover，不使用模态框；
- 重命名使用行内编辑；
- 删除、取消 Run、选择或改选 Final 使用 Dialog；
- 普通成功反馈使用 Toast，不抢占 Dialog 容器；
- Menu 支持点击外部和 Esc 关闭，关闭后焦点返回触发按钮；
- Dialog 支持 Esc、取消按钮和合理的初始焦点；
- 点击行级操作不会同时触发行打开；
- 保存、确认、重新生成是三种不同动作；
- 所有锁定项提供不可用原因，不出现无反馈点击。
