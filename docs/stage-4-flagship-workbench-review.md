## 2. 已落实的视觉决策

1. 左侧使用连续目录，不使用项目卡片堆叠。
2. 中间使用单一纸面工作区，Artifact 是页面视觉主角。
3. 右侧 Agent 使用连续时间线，运行、同步和确认属于同一上下文。
4. 业务确认只放在 Agent 时间线 ApprovalCard 中；产物工具栏只保留编辑或当前步骤必要操作。
5. 仅业务级模块使用边框；状态主要依靠排版、圆点和语义色表达。
6. 全屏保持浅色、低噪声、适合长时间阅读，不使用渐变、玻璃效果或装饰性背景。
7. 1920 宽屏限制正文阅读宽度并居中，不让文本随视口无限拉长。
