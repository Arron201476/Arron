# 视频整剧解析：33 集运行后优化清单

状态：等待作品 `prj_ee7f2277829fb474dac0cd042fff0c77` 的 33 集解析完成后处理。

## 1. 跨集人物身份与命名一致性

现象：同一人物在不同集被识别为不同名称，例如“祖母”“命运女神”。当前逐集任务彼此独立，单集模型无法获得稳定的全剧人物身份。

目标方案：

1. 逐集脚本生成前，允许并行提取人物候选、明确姓名、称谓、关系、关键画面与时间码。
2. 汇总候选并建立全剧人物表，使用稳定 `character_id` 关联跨集同一人物。
3. 对低置信度的合并请求用户确认，不强行归并。
4. 详细剧本生成或最终归一化必须读取同一份人物表。
5. 不把上一集完整剧本依次塞给下一集，以免阻断并行并传播早期错误。

验收：同一人物跨集名称一致；别名和关系称谓可追溯；3-5 集并行时结果不退化。

## 2. 时间码柔性修复与定位可信度

现象：模型可能返回零时长或超出视频时长的场次。当前归一化会把无效范围裁剪为视频末尾最后 1ms，导致多个场次显示为同一个 `01:48 - 01:48`，虽然不再整集失败，但定位不可用。

目标方案：

1. 优先根据场内台词、动作和来源引用的有效时间码重建场次范围。
2. 其次使用前后场次边界修复，保持顺序且避免重叠。
3. 仅对轻微零时长问题执行确定性扩展。
4. 无法可靠恢复时保留剧本，标记 `timecode_status=needs_review`，前端不展示可点击的伪精确定位。
5. JSON、来源快照、集号错位等实质错误继续阻断；可恢复时间码不得使整集失败。

验收：不再因可恢复时间码导致整集失败；场次定位不重叠、不越界；不可确认的定位明确降级展示。
