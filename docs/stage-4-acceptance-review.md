## 1. 产品结构

- 一个作品对应一个独立上下文。
- 一个生成 Run 只选择小说、非小说文本或视频参考创作中的一条主链。
- 未启用 Skill 时，General Agent 仍可聊天、理解意图、管理文件与项目上下文。
- 中间区域负责 Artifact 阅读、编辑和版本；右侧 Agent 负责状态、审批、失败、暂停与恢复。
- 第一版最终只确认一个剧本，确认前的候选和修订历史继续保留。

## 3. 当前结论

以下结构和流程门禁仍可沿用：

1. 核心剧本编辑与版本闭环。
2. 三条主链来源与检查点确认。

5. 1280/1440/1920 响应式结构。
