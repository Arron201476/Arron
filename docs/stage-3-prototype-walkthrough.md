## 5. 探索测试限制

当前任务未暴露可控制现有 in-app Browser 的 Computer Use 接口；尝试通过 Node REPL 启动浏览器受到系统 `spawn EPERM` 限制。

本轮实际采用：

1. 获得系统许可后由 Playwright 启动本机 Chrome；
2. 按真实用户顺序执行八条 P0 路径；
3. 保存关键步骤截图；
4. 使用图像查看工具逐张检查截图；
5. 根据视觉检查修复 Toast 堆叠和导出交互。

因此浏览器流程、DOM、键盘和视觉截图均已验证，但没有声称使用了不可用的 in-app Computer Use 控制接口。
