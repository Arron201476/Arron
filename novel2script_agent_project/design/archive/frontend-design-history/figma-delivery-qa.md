## 2026-06-30 返修记录

本轮根据用户复查截图追加修正：

1. 修复右侧 Agent 聊天中用户消息的展示方式：用户消息右对齐，文本宽度与气泡宽度匹配，不再出现文本越界。
2. 修复按钮源组件和 frame 内按钮：`发送`、`确认继续`、`暂停` 等按钮文案必须水平、垂直居中，并保证按钮宽度能容纳中文文案。
3. 修复 StatusBadge 源组件：状态徽标宽度必须容纳 `待生成`、`生成中`、`待确认`、`已生成`、`修改中`、`失败` 等中文文案。
4. 剧本文档视图全部补充分集目录：小说剧本完成、非小说剧本完成、AI 修改建议、应用修改后、报错重试等含 `ScriptDocument` 的 frame 都必须包含 `EpisodeDirectory`。
5. 非剧本中间态内容卡片统一在中间内容区居中，避免卡片偏上、偏左造成工作区不平衡。
6. 返修后重新执行全局 QA：父子边界、按钮居中、剧本目录存在性、非剧本内容区水平居中均为 0 issues。

## 2026-06-30 二次布局返修

本轮继续根据复查截图修正布局规则：

1. 剧本视图中，`EpisodeDirectory` 必须和 `ScriptDocument` 并列出现在中间栏内，目录不保留明显右侧空白。
2. `ScriptDocument` 必须完整留在中间内容区，不得侵入右侧 Agent 面板。
3. 所有包含剧本文档的状态图都执行同一布局：左侧分集目录，右侧正文画布。
4. 除剧本外的过程产物卡片，不再垂直居中；统一为中间内容区顶部居中，因为真实内容会逐步增长。
5. 返修后重新执行全局 QA：正文不越过 Agent、剧本文档均有目录、非剧本内容顶部居中、父子边界均为 0 issues。

## 2026-06-30 三次返修记录

本轮继续根据用户复查截图修正，重点处理组件源头和状态 frame 的联动问题：

1. 修复 `AgentComposer`：`发送` 按钮固定最小宽度并水平 / 垂直居中，避免中文按钮被裁切或贴边；上传入口只保留圆形 `+`，并保证符号在圆内居中。
2. 修复右侧 Agent 聊天流：用户消息、Agent 回复、任务步骤、确认卡、修改建议卡、完成卡、错误卡统一按聊天流垂直排列，避免用户消息与下一张卡片重叠。
3. 修复剧本态编辑器：所有包含 `ScriptDocument` 的 frame 都补齐 `EpisodeDirectory + ScriptEditorToolbar + ScriptDocument`，工具栏位于正文编辑器正上方，并与正文画布同宽。
4. 修复剧本画布边界：正文编辑器限制在中间内容区内，不侵入右侧 Agent 面板；分集目录与正文工具栏顶部对齐。
5. 修复非剧本过程产物布局：中间内容不再垂直居中，而是置顶居中展示，符合真实内容会逐步增长的使用场景。
6. 重新执行 QA：`06 State Frames` 29 张 frame 的 Agent 消息重叠、按钮/加号居中、剧本目录存在、剧本工具栏存在、正文不压右侧、非剧本内容置顶居中检查均为 `0 issues`。
7. 重新执行组件 QA：`02 Components`、`04 Agent Components`、`05 Script Editor Components` 的按钮、图标按钮、Agent Composer、剧本工具栏居中与尺寸检查均为 `0 issues`。

## 2026-06-30 四次专项返修

本轮根据复查截图补充两类细节修正：

1. 修复 `ErrorCard` 的 `重试` 按钮：按钮容器不得被压缩成窄条，最小宽度按普通按钮处理，中文文案必须水平 / 垂直居中。
2. 修复剧本正文选区表达：选区不是覆盖在文字上方的卡片或标签，不显示“选中片段”；只用正文文字背后的浅蓝背景表示选中范围。
3. 选区背景只允许出现在局部修改态，例如 `通用 02｜AI 修改建议`；应用修改后和报错重试状态不得保留选区背景。
4. 专项 QA 结果：重试按钮尺寸与居中、选区背景层级、选区标签清理、非局部修改态无选区残留均为 `0 issues`。
