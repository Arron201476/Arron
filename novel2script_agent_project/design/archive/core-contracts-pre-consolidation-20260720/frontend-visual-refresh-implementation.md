# 前端视觉交互刷新实施记录

更新时间：2026-07-14

## 改动边界

本轮为纯前端改造，没有修改后端接口、Agent 意图判断、产物数据结构、局部修改粒度、审批决策或运行状态机。

现有接口已经能够提供本轮界面所需的产物类型、版本、状态、消息、执行步骤和审批数据，因此不需要前后端联合改造。

## 已完成

### 工作区空间

- 桌面端可以独立收起左侧目录和右侧 Agent。
- 收起后中间阅读和编辑区自动占用释放的空间。
- 桌面端左右栏支持拖动和键盘调整宽度，双击分隔线恢复默认宽度，刷新后保持宽度偏好。
- 1280px 以下进入“内容常驻 + 一个侧栏”的中等宽度模式；760px 以下进入“目录 / 内容 / Agent”单区域模式。
- 从目录选择产物后自动进入内容区。
- 收起后的恢复入口只出现在对应边缘，不再把展开按钮集中到右上角。
- 生成、修改、审批和快照刷新只更新状态，不主动改变用户当前产物、视图和滚动位置。
- 每个作品分别恢复上次查看的视图和内容滚动位置。

### 过程产物

- 不再默认把全部过程产物串成一张长页面。
- 左侧作品目录作为唯一流程切换入口，中间不重复展示横向 artifact 切换栏。
- 每次聚焦阅读一个产物。
- 一级字段分组支持展开和收起。
- 默认展开前三个有效字段组，空字段默认收起。
- 常见内部枚举转换成中文产品语言。

### Agent 面板

- 长消息默认显示摘要，可以展开和收起完整内容。
- 已完成步骤默认只显示最近两步，可以查看全部步骤。
- 当前审批和下一步操作保持高优先级展示。
- 确认卡按钮支持自动换行，不在窄面板中重叠。

### 剧本编辑器

- 清除格式和保存改为标准图标按钮，保留悬停提示和无障碍名称。
- 默认桌面宽度下工具栏已经没有横向溢出。
- 窄屏时分集目录改为横向切换，正文区域独占宽度。

## 回归结果

- 前端 TypeScript 与生产构建通过。
- 后端全量 Go 测试通过。
- 浏览器控制台没有 error 或 warning。
- 桌面端左右栏收起与恢复通过。
- 产物切换、字段折叠、历史消息展开和步骤展开通过。
- 1024px 的“内容 + 目录”“内容 + Agent”双区切换通过。
- 390px 的目录、内容、Agent 单区域切换通过。
- 下游保留/重新生成确认卡未发生按钮重叠。
- 剧本工具栏 `scrollWidth` 与 `clientWidth` 一致，无横向溢出。

## 追加修复：产物编辑态宽度

- 修复过程产物进入“编辑内容”后，表单容器按最小内容宽度收缩的问题。
- `.artifact-stack` 现在始终占满过程产物内容栏。
- 桌面端实测：内容栏、编辑卡片均为 682px，文本框为 650px。
- 768px 窄屏实测：编辑卡片约 712px，文本框约 680px。
- 编辑、取消和响应式切换验证通过；未执行无内容变化的保存，避免给真实产物新增无意义版本。

## 追加改进：产物编辑安全

- 编辑页顶部操作栏保持可见，长产物滚动后仍可保存或取消。
- 只有内容实际变化后才启用保存，并显示“有未保存修改”。
- 字段目录和对应内容区只标记真正发生变化的一级字段，帮助用户确认修改范围。
- 有未保存内容时，切换产物、视图或重置工作区会先提示“保存后继续 / 放弃修改 / 继续编辑”。
- 保存说明明确：保存只创建当前产物的新版本，不会立即覆盖已经生成的下游内容；若存在下游影响，继续使用既有的保留或重新生成确认流程。
- 页面刷新或关闭浏览器时，如果仍有未保存内容，使用浏览器原生离开提醒兜底。
- 手动保存完成后立即重新读取当前运行快照，让新版本、审批状态和下游影响提示同步刷新。
- 窄屏编辑过程中出现待确认事项时，只在 Agent 入口显示提醒，不强制切走当前编辑内容。
- 左右面板的展开状态保存在当前浏览器中，刷新后保持用户上次选择。

## 数组编辑边界

- 现有数组项继续支持逐字段修改。
- 本轮不增加通用“新增空项 / 删除项”按钮。人物、分集、场景等数组的必填字段、稳定 ID 和排序规则不同，通用空对象会破坏产物结构。
- 后续增删项必须依据各 artifact schema 分别实现，并在保存前校验必填字段和稳定 ID；不能用一个无约束的递归表单覆盖所有数组。

## 编辑安全回归

- 初始编辑态未修改时，保存按钮不可用。
- 修改人物字段后，仅“人物”分组显示已修改标记。
- 离开编辑页时拦截成功；“继续编辑”保留草稿，“放弃修改”恢复原数据并完成跳转。
- 768px 视口下编辑卡宽约 712px，页面无横向溢出。
- 面板折叠状态刷新后可以恢复，测试结束后已还原目录展开状态。
- 左栏拖动到 280px 后刷新仍保持 280px，双击恢复到默认 224px。
- 1440px、1024px、390px 三种视口均无页面级横向溢出。
- 未将临时回归文字保存到真实项目，避免制造无意义 artifact 版本。
- 前端生产构建和后端全量 Go 测试通过，浏览器控制台无 error。

## 后续边界

如果后续要增加“产物摘要由模型单独生成”“用户自定义面板宽度跨设备保存”或“服务端保存界面偏好”，才需要新增后端字段或接口。本轮不需要。
