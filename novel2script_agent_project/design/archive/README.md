# 历史设计资料

本目录保存 Novel2Script Agent 已被替代或已完成使命的设计资料，文件未删除，仅从 `design/preview.html` 的当前核心文档导航中移除。

## 分类

- `core-contracts-pre-consolidation-20260720/`：2026-07-20 代码反向审计前的 25 份核心合同和可视化参考，已由七份现行规范替代。
- `product-discovery/`：早期产品研究、线框、评审清单和开发准入分析。
- `frontend-design-history/`：旧视觉稿、Figma 交付资料、组件方案和编辑器技术试验。
- `implementation-history/`：旧技术路线、Mock 阶段方案、Eino 接入过程、阶段审计和修复记录。
- `python-prototype/`：已被 Go + Eino 正式实现替代的 Python 原型。

## 使用规则

1. 历史资料只用于追溯决策，不作为当前开发合同。
2. 当前产品和技术结论以 `design/INDEX.md`、其列出的核心合同、运行代码和测试为准。
3. 新的阶段性审计完成后，如不再承担长期合同职责，也应归档到这里。
