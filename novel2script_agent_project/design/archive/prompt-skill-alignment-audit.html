审计原则

  • Skill 只提供准则，不提供输入、输出、参数、字段协议。
  • Prompt 引用 skill 的前提：当前步骤的执行规则或输出 artifact 会实际使用这些准则。
  • 如果只是通过上游 artifact 间接使用，不应重复引用上游 skill；prompt 应消费 artifact 字段，而不是再引用生成 artifact 的 skill。
  • 如果 prompt 输出了某个字段，但没有引用能支撑该字段的 skill，要补引用或把准则移到已引用 skill 中。
  • 如果 skill 中某些准则没有任何 prompt 输出承接，要么补 artifact 字段，要么标记为暂不启用，不让它悬空。
