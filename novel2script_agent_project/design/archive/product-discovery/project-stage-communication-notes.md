Novel2Script Agent 当前还没有进入正式前后端开发主阶段。

当前主阶段：

- `4. UI / UE 规范`
- `5. 技术方案`

## 后续回复格式代办

每次阶段性回复都应包含：

```text
当前已完成
- ...

当前所在阶段
- 通用产品开发阶段：...
- Novel2Script 当前具体阶段：...

下一步应该干嘛
- ...
```

如果是很短的确认回复，也至少说明：

```text
当前已完成：...
当前所在阶段：...
下一步应该干嘛：...
```

## 阶段口径规则

- 不把“写了 mock / spike”说成“前端实现完成”。
- 不把“写了 API 合同”说成“后端完成”。
- 不把“截图审计通过”说成“E2E 完成”。
- 不把“UI gallery”说成“最终 UI 定稿”。
- 不把“模型接通一次”说成“Agent 流程完成”。
- 每次进入新阶段前，要明确上一阶段的准入证据。
