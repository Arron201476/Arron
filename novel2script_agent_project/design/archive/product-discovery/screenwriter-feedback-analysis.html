编剧反馈二次归类：按 Agent 版落点整理

基于用户逐条判断更新：不把所有问题都做成前端功能，优先区分 generation profile、agent 修改能力、prompt/artifact 字段、skills 准则、延期项。

总判断

合理

用户判断整体成立

多数反馈不是前端按钮问题，而是 agent 运行策略、全局生成配置、局部修改能力、规划/剧本 skills 准则的问题。

边界

参数不进 skill

选项、用户要求、是否保留原文、是否有字幕等是 `generation_profile` 参数；skill 只沉淀准则，不放输入输出。

核心

局部修改是主能力

第 2 和第 11 条本质一致：Agent 必须识别用户修改的是哪个 artifact、哪个位置、哪个局部范围，并只重跑受影响部分。

延期项：第 9、10、15 条先标记，不进入当前落地范围；第 14 条现有声口 skill 没明确覆盖方言/地域口音，需要后续补一条准则。
