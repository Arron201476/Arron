# 当前运行、安全与发布规范

更新时间：2026-07-20

## 本地开发

`scripts/dev.ps1` 先检查服务存活，不盲目重启。开发地址：后端 `127.0.0.1:8831`，前端 `127.0.0.1:8832`。

后端配置放在 `backend/.env`，不得提交或打入正式包。模型 Provider 通过 OpenAI-compatible 接口接入；前端不接触 API Key。

## 数据与日志安全

- 附件、原文、聊天和剧本保存在本机作品数据中。
- 模型 trace 默认使用 `metadata`，只记录耗时、模型、字符数、请求 ID 和运行定位，不保存完整原文、Prompt、响应或 Provider 错误正文。只有显式设置 `N2S_LLM_TRACE_LEVEL=full` 的调试环境才会记录完整请求与响应，该模式包含敏感内容，不能用于常规运行、备份或对外分享。
- 面向用户的错误经过脱敏；SQLite、路径和 Provider 内部细节不直接显示。
- 正式停止接口使用启动时生成的本地令牌，避免任意网页关闭服务。

## 备份与恢复

备份前停止服务。`backup-data.ps1` 只打包两份 SQLite 状态数据库，不包含 `.env`、API Key 和模型 trace。`restore-data.ps1` 要求显式确认并在恢复前保存当前数据副本。`view-logs.ps1` 输出脱敏日志摘要。

## 正式包

`package.ps1` 输出 `release/Novel2ScriptAgent`，包含 Go 可执行文件、生产前端、启动/停止脚本和备份工具。正式包在同一地址提供 SPA 和 API，默认使用 Eino，不包含源码数据、测试数据、现有作品数据库或密钥。

## 发布门禁

`release-gate.ps1` 必须一次通过：

1. 前端单元与组件测试；
2. Go 全量测试；
3. `go vet ./...`；
4. Lexical 编辑器专项 gate；
5. 前端生产构建；
6. 后端正式构建；
7. `design/preview.html` 存在。

发布前还需检查正式包不含 `.env`、密钥、数据库和用户内容，并完成一次启动、健康检查、备份、恢复和安全停止演练。
