# 02_人物关系与声口

## 名称
02_人物关系与声口

## 用途描述
用于 Step1 的人物关系整理、Step3 的人物变化规划、Step4 的人物声口一致性控制。

## 准则
### 短剧人物引擎


### 参考范围

参考问题：

- 主角目标不清
- 人物被动
- 反派脸谱化
- 配角没有功能
- 情感关系没有推进
- 人物说话和行动不一致
- 成长弧缺少节点

### 使用原则

1. 人物必须有欲望、阻力、行动和代价。
2. 人物深度服务剧情推进，不写无用履历。
3. 人物重塑要在前期设定中锁定，不在剧本正文阶段临时改底层设定。
4. 人物行为必须符合当前集处境和前后集状态。
5. 安静场景可以保留，但必须承载关系变化、态度变化、伏笔或情绪推进。

### 人物检查项

#### 1. 主角

必须明确：

- 想要什么
- 害怕什么
- 为什么不能退
- 当前最缺什么
- 什么时候第一次主动行动
- 每个阶段如何变化

主角不能长期只被压迫而不行动。

#### 2. 主要对手

必须明确：

- 阻止主角的原因
- 可见行动
- 资源优势
- 情绪弱点
- 升级手段

反派不能只靠骂人制造冲突。

#### 3. 关键关系人物

必须明确其功能：

- 提供情感压力
- 提供误会
- 提供证据
- 提供资源
- 推动主角选择
- 暴露真相

没有功能的配角应减少戏份。

### 禁止越权

1. 不新增原文没有的核心人物关系。
2. 不让人物为了钩子突然做违背动机的事。
3. 不用人物小传替代剧情场景。
4. 不把所有角色写成同一种爽文口吻。
5. 不为了人物复杂度牺牲短剧清晰度。

---

### 人物声口提示

声口规则不在此处压缩删除；完整对白规则保留在 05_对白规则.md。人物设定阶段只需要提前记录人物身份、关系位置、语言风格、攻击方式、隐瞒方式和情绪表达习惯。

---

### 地域/方言声口边界

1. 只有原文、用户要求或人物设定明确给出地域、阶层、职业、年龄和成长背景时，才使用地域化声口。
2. 方言或口音只能少量点到为止，优先体现在称谓、语气词、短句节奏和惯用表达，不整段改写成难读方言。
3. 方言必须服务人物身份、亲密关系、冲突压迫或喜剧反差；如果不能服务剧情功能，就保持普通话表达。
4. 同一人物的地域化表达要稳定，不在不同集数突然切换口音或语言风格。
5. 严肃冲突、关键信息、证据揭示和情绪爆发场景，要优先保证观众读懂，不为方言牺牲信息清晰度。
6. 不因地域声口制造刻板印象，不把地域标签当成人物性格本身。
