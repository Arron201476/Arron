# 当前前端与编辑交互规范

更新时间：2026-07-20

## 工作区

前端是 React + TypeScript 三栏工作台：左侧作品与产物目录，中间输入材料/过程产物/剧本/过程记录，右侧 Agent 对话。

左右栏可独立收起、从对应边缘展开、拖动或键盘调整宽度；宽度和开合状态保存在本地。中等宽度只保留一个侧栏，移动端在目录、内容和 Agent 之间单区切换。

作品切换和页面刷新恢复用户上次视图、当前 Artifact 和内容滚动位置。生成、审批和快照刷新只更新数据，不主动抢走用户当前选中项或滚动位置。

## 中间内容区

- 尚无过程产物：顶部显示“输入材料”，附件和正文直接可见，不要求滚到底部查看。
- 有过程产物：左侧固定目录只负责定位，只有右侧产物内容滚动。
- 剧本：固定分集目录加正文编辑器；过程产物与剧本使用同一中栏宽度，切换时不横向跳动。
- 过程记录：默认展示面向用户的步骤摘要，详细事件按需展开，不暴露内部引用 ID 和无意义字段。

## 过程产物编辑

阅读态按 Artifact 字段组织中文结构，未知字段仍完整展示。点击编辑后保持同一内容宽度和目录可见，字段、对象和列表在原位置编辑；列表支持新增、删除和排序。

离开未保存编辑时必须询问保存、放弃或继续编辑。保存使用 `base_version`；发生冲突时加载服务端最新版本并提示用户，不覆盖新内容。

Run 正在生成时编辑入口禁用，并明确说明完成或暂停后可以编辑。

## 剧本编辑器

正式编辑器为 Lexical。每个 episode、scene 和 line 使用稳定 ID；支持行间新增、删除、撤销、重做、粗体、斜体、下划线、删除线和手动保存。

分集聚合视图只读，编辑落在对应 `script_unit`。人物名样式是现有文本结构的展示结果，不要求用户手工创建不可编辑的标签。

选区支持单行局部和跨行/跨场景范围。发送后，选区引用显示在用户消息里，输入区的“已引用选区”随发送清空；Agent 修改结果通过新的 Artifact 版本返回，不使用独立的建议接受/拒绝卡。

## Agent 对话

聊天中只展示用户消息、Agent 回复、必要的运行摘要和当前有效审批卡。历史审批卡不可再次操作。明确意图直接执行，模糊意图先追问；界面不能同时显示“询问确认”和“任务已经开始”。
