# 当前验收规范

更新时间：2026-07-20

## 自动化门禁

```powershell
./scripts/test.ps1
./scripts/release-gate.ps1
```

任何核心文档、Prompt、Rule、Skill、Agent、Runtime、API 或编辑器改动都必须运行对应测试；准备发布时必须运行完整 release gate。

## 产品路径验收

1. 新建两个作品，确认聊天、附件、Run、Artifact、视图和滚动位置完全隔离并可在刷新后恢复。
2. 闲聊、上传附件、查看材料都不启动 Run；明确生成时正确出现生成配置。
3. 完整跑通小说链和非小说链，逐节点确认，最终得到目标集数的 `script_unit` 和聚合 `scripts`。
4. 小说拆集和两条链的分集卡覆盖超过 5 集的批次，验证进度、检查点、合并和失败续跑。
5. 对两条链所有主要 Artifact 分别验证字段、实体、集合、段落和整体重生成；剧本验证单行、跨行、场景和单集修改。
6. 有下游与无下游分别验证：无下游不弹确认；有下游可保留或只重生成实际受影响内容。
7. Run 进行中无法编辑和发送新执行消息；暂停后可以编辑，恢复从 cursor 继续。
8. 失败步骤只能从失败 task 重试；模型超时明确显示“模型服务超时”。
9. 手动保存和 Agent 修改都递增版本；旧版本 superseded；并发旧版本保存返回 409。
10. 单行和跨行选区发送后在用户消息中保留引用，定位与刷新正确，未选中内容不发生变化。

## 接口与数据验收

- 正式路由矩阵全部可达，旧旁路接口被拒绝。
- SSE 断开后快照刷新能够恢复状态，不重复消息、事件或 Artifact。
- 服务重启后恢复待审批、失败 cursor、Artifact 版本和聊天记录。
- 数据库忙、持久化失败和未来 schema 版本都返回明确错误，不制造“前端成功、后端未保存”。

## 发布验收

- 干净机器可用正式包启动并访问同一地址。
- 包内没有 `.env`、API Key、现有数据库、原文、剧本或 trace。
- 备份、恢复、日志查看和安全停止可执行。
- `design/preview.html` 只包含本索引、七份现行规范以及运行时 Prompt/Rule，不再混入历史合同。
