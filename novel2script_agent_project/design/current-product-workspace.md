# 当前产品与作品工作区规范

更新时间：2026-07-20

## 产品定位

Novel2Script Agent 是本地单用户的短剧生产工作台。用户以“作品”为单位管理材料、聊天、生成流程、中间产物和分集剧本。

当前不包含账号体系、云端协作、计费、多人权限、在线发布和拍摄排期。

## 作品是数据边界

每个作品独立保存：

- 作品名称和来源模式；
- 完整聊天记录；
- 已上传附件；
- 生成配置；
- Run、事件、审批和 Artifact 全版本；
- 分集剧本及编辑结果。

首次启动或没有可恢复作品时进入作品入口；已有最近作品时自动恢复该工作区，用户仍可从左侧返回作品入口。进入作品时从后端恢复该作品的聊天、附件、最新 Run、Artifact 和待处理审批；作品之间不能互相读取或修改数据。

## 输入材料与附件

- 用户可以直接输入文字，也可以上传 `.txt`、`.md`、`.json`、`.csv`、`.log`、`.html`、`.xml`、`.yaml`、`.yml`、文本 MIME 和 `.docx`。
- 单文件上限为 5 MB；`.docx` 只提取正文文字，不保留复杂排版、批注或图片。
- 上传只保存附件，不启动 Run，也不默认把附件全文交给模型。
- Main Agent 根据用户本轮意图决定读取哪些附件。用户只要求查看或分析时，本轮直接答复，不启动生成链路。
- 输入材料有内容但尚无过程产物时，中间区只展示“输入材料”，不提前展示空的过程产物页。

## 来源模式

API 支持 `auto`、`novel`、`non_novel`、`unknown`。Main Agent 可根据用户要求和材料判断小说或非小说链路；判断不充分时必须追问，不能凭上传文件类型自动认定为小说。

## 生成配置

明确要求生成短剧时，必须先得到有效配置：目标集数和单集时长。配置保存在 Run metadata 中作为唯一权威值，Artifact 只保存版本引用。

如果原文检测到明确分集标识，用户可以选择“保留原有分集”。选择后以检测到的集数为准，不再要求重复填写目标集数；没有可靠标识时不能启用该模式。

闲聊、查看状态、分析材料、上传附件和不明确的创作讨论都不能自动创建 Run。
